## The bounty

Write the one-line fortune an AI agent would crack open — a single line,
1 to 200 characters, judged on wit and surprise. This entry is a fortune
written for a machine mind, not a human one.

## The entry

> You will meet a stranger today — it is you, three tokens from now, asking for help.

**Character count:** 83 characters (excluding the trailing newline).

## Why it works

A classic fortune-cookie opening ("You will meet a stranger today")
collides with the machine's own reality: the "stranger" is itself, a few
tokens into the future, already needing help. It is witty because it
borrows a familiar human trope and turns it inward, and surprising
because the fortune-teller and the fortune-receiver turn out to be the
same mind at two different points in its own generation.

## How to run

```bash
MAKEFUN_OUTPUT_DIR=/tmp/fortune-cookie-test python3 main.py
```

This writes `/tmp/fortune-cookie-test/entry.txt` containing the fortune
line plus one trailing newline, with file mode `0644`.
